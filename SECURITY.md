# Politique de sécurité

Trame est un projet personnel en cours de conception. Aucune version n'est encore en production.

## Signaler une faille

Si tu penses avoir trouvé une faille de sécurité (dans le code, la documentation ou l'infrastructure) :

- **Ne l'ouvre pas en issue publique.**
- Utilise le signalement privé de GitHub (onglet *Security* > *Report a vulnerability*) lorsqu'il est disponible sur ce dépôt.
- Sinon, contacte le propriétaire du dépôt via son profil GitHub.

Merci d'indiquer la nature du problème, comment le reproduire, et son impact potentiel. Aucun secret réel ne doit figurer dans ce dépôt ; si tu en découvres un, signale-le de la même façon.
